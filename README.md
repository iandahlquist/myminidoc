# myminidoc
## Quarto Website
This is my minidoc site repository built in [Quarto].(https://quarto.org)

## What this Project Needs. 
- Visual Studio Code (VSCode)
- Quarto
- Quarto extension within VSCode
  
## Preview
Use the command:

```bash
quarto preview
```

Within the project directory to get a fully rendered preview within a browser. As you save changes in VS Code, this preview will update, giving you an accurate visual of what your site looks like.
