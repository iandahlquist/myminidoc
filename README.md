# myminidoc
## Quarto Website
This is my minidoc site repository built in [Quarto].(https://quarto.org)

## What this Project Needs. 
- Visual Studio Code (VSCode)
- Quarto
- Quarto extension within VSCode
  
## Preview
Use the command:

```bash
quarto preview
```

Within the project directory to get a fully rendered preview within a browser. As you save changes in VS Code, this preview will update, giving you an accurate visual of what your site looks like. 

Use:

```bash
control + C
```

To terminate the preview. 

## Render the Website

To generate the complete website, use the command: 

```bash
quarto render
```
in the project terminal. 

By default, the rendered site will be written to the "_site" directory. 

## Publishing

The webstire can now be published using GitHub Pages. Make sure to push and committ all changes!
